# PCB Defect Detection Project

Academic project for the course **Systèmes intelligents**.

## Objective
Develop an intelligent system for PCB defect detection using computer vision and deep learning.

## Dataset
PCB Defects dataset:
https://www.kaggle.com/datasets/akhatova/pcb-defects

## Project files
- `train.py` : training script
- `evaluate.py` : evaluation script
- `predict.py` : inference / prediction script
- `requirements.txt` : dependencies
- `.gitignore` : ignored files
- `README.md` : project description
